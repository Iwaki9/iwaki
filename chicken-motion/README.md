# Курица клюёт зёрна — motion study

Восьмисекундная зацикленная анимация: курица в утреннем дворе клюёт зёрна.
Всё нарисовано кодом (canvas 2D), без картинок и внешних библиотек в рантайме.

**Смотреть:** откройте `index.html` (или `python3 -m http.server` в этой папке).

| файл | что это |
| --- | --- |
| `index.html` | интерактивный плеер: пауза, скраббинг по таймлайну, скорость, «чистый кадр». Самодостаточный — сцена встроена внутрь |
| `out/chicken-pecking-grains.mp4` | H.264, 1280×720, 30 fps, ровно 8.00 с, бесшовная петля |
| `out/chicken-pecking-grains.gif` | 560×315, 15 fps, палитра 192 цвета (превью для чатов/README) |
| `out/poster.png` | кадр 0 — постер 1280×720 |
| `src/scene.js` | сама сцена: геометрия, тайминг, отрисовка |
| `src/render.mjs` | рендер PNG-серии через `@napi-rs/canvas` |
| `src/export.sh` | рендер + сборка MP4 / GIF / постера |
| `src/build-html.mjs` | вклеивает `scene.js` в `index.html` |

## Монтажный лист (8 с)

| время | фаза | что происходит |
| --- | --- | --- |
| 0.00–1.42 | осмотр | дыхание, лёгкое покачивание, взгляд по сторонам, моргание на 0.72 |
| 1.42–2.56 | клевок | замах 0.34 с (голова вверх-назад, корпус приседает) → удар 0.15 с → контакт на 1.91 → возврат с перелётом |
| 2.56–3.10 | пауза | шея выпрямляется, зоб «проглатывает» |
| 3.10–4.86 | двойной клевок | два удара подряд (3.59 и 4.23) — ритмическая вариация |
| 4.86–5.44 | подбор | короткая пауза, взгляд вниз |
| 5.44–6.44 | клевок | третий одиночный удар на 5.93 |
| 6.44–8.00 | шаг | перенос веса, шаг передней лапой, осмотр → встык к началу петли |

Удары: **1.91 · 3.59 · 4.23 · 5.93**. Каждый удар: облачко пыли, ударная волна по земле, крошки, искры, исчезновение зерна.

## Как это сделано

* Поза — чистая функция от времени: `chickenState(t)` считает наклон корпуса, длину и угол шеи,
  поворот головы, раскрытие клюва, моргание, IK лап и вторичную анимацию (хвост, гребень, серьга)
  аналитически. Никакого состояния между кадрами — поэтому кадр можно отрендерить в любой момент,
  и браузер с Node дают идентичный результат.
* Все периодические движения кратны длине петли (`LP = 2π / 8`), поэтому стык 8.00 → 0.00 бесшовный
  (проверяется скриптом: расхождение позы через петлю = 0).
* IK лап: две кости (бедро/цевка), колено смотрит назад — как у птицы; стопа фиксирована на земле,
  при клевке корпус приседает и наклоняется, лапы складываются сами.
* Клюв доводится до зерна: позиция кончика клюва в момент удара считается из той же модели,
  ближайшее зерно «съедается» ровно в этот кадр.
* Композиция: камера с медленным дрейфом, три плана (небо/холмы/забор → земля → передняя трава),
  тёплый грейд и виньетка.

## Пересборка

```bash
npm install                 # @napi-rs/canvas (только для рендера в файлы)
node src/build-html.mjs     # пересобрать index.html после правок scene.js
npm run export              # PNG-серия → MP4 + GIF + постер (нужен ffmpeg)
```

Быстрый предпросмотр отдельных кадров:

```bash
node src/render.mjs --times 1.0,1.91,3.59 --out /tmp/stills
```

## Горячие клавиши плеера

`Space` — пауза/пуск · `←` `→` — по одному кадру (1/60 с) · `H` — скрыть интерфейс · `R` — с начала.
Таймлайн можно тянуть мышкой, скорость — 0.25× / 0.5× / 1×.

## Что легко поменять

* Ритм клевков — массив `PECKS` в `src/scene.js` (`start`, `power`, `hold`).
* Палитра — объект `P` там же.
* Длина петли — константа `DURATION` (частоты пересчитываются автоматически через `LP`).
* Количество и раскладка зёрен — генератор `grains` (детерминированный seed).
